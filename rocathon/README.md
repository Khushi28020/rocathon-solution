# RoCathon — Hybrid Creator Search Engine

A hybrid search engine that ranks TikTok creators by both **semantic relevance** (vibe) and **commerce performance** (GMV), built for the RoCathon hackathon by ReturnOnCreators.

---

## How it works

```
Query (natural language)
        │
        ▼
   Embed with OpenAI text-embedding-3-small
        │
        ▼
   pgvector HNSW cosine search → Top 50 by semantic similarity
        │
        ▼
   Hybrid re-ranking:
   final_score = (semantic × 0.45) + (projected_norm × 0.55)
        │
   + Brand profile adjustments:
     · Zero GMV  → ×0.60 penalty  (hard rule)
     · Industry mismatch → ×0.90 soft penalty
     · Gender mismatch   → ×0.85 soft penalty
        │
        ▼
   Sorted RankedCreator[]
```

**Key design decisions:**

- **HNSW index** satisfies the "no linear scan" hard constraint and scales well.
- **Projected score normalisation**: `(score - 60) / 40` maps 60–100 → 0–1, same scale as cosine similarity.
- **Zero-GMV penalty (×0.60)** enforces the challenge's hardest rule: perfect vibe + $0 GMV always loses to good vibe + real sales.
- **Industry alignment** rewards creators whose tags overlap with the brand's industries, while still surfacing cross-category gems with strong GMV.

## Setup

### 1. Clone + install

```bash
git clone <your-repo>
cd roc-hackathon
npm install
```

### 2. Configure environment

```bash
cp .env.example .env
```

Fill in `.env`:

```
OPENAI_API_KEY=sk-...
EMBEDDING_PROVIDER=openai

# Local Docker (Option A):
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/rocathon

# Supabase (Option B):
# DATABASE_URL=postgresql://postgres:[password]@[host]:5432/postgres
```

### 3. Start the database

**Option A — Local Docker:**

```bash
docker compose up -d
```

**Option B — Supabase free tier:**

- Create a project at supabase.com
- SQL Editor → `CREATE EXTENSION IF NOT EXISTS vector;`
- Copy connection string into `DATABASE_URL`

### 4. Ingest creators

```bash
npm run ingest
```

Embeds all 200 creators and stores them with an HNSW index. Takes ~2–3 minutes.

### 5. Run the demo

```bash
npm run demo
```

Runs the required query, prints top-10 table, writes `output_brand_smart_home.json`.

## DB schema

```sql
CREATE TABLE creators (
  id              SERIAL PRIMARY KEY,
  username        TEXT UNIQUE NOT NULL,
  bio             TEXT,
  content_style_tags TEXT[],
  projected_score FLOAT,
  metrics         JSONB,
  embedding       VECTOR(1536)
);

CREATE INDEX creators_hnsw_idx
ON creators
USING hnsw (embedding vector_cosine_ops)
WITH (m = 16, ef_construction = 64);
```

## Scoring weights

| Signal | Weight | Notes |
|---|---|---|
| Semantic similarity | 0.45 | Cosine similarity from pgvector |
| Projected score (normalised) | 0.55 | (score − 60) / 40 → 0–1 |
| Zero GMV multiplier | ×0.60 | Hard rule |
| Industry mismatch | ×0.90 | Soft penalty |
| Gender mismatch | ×0.85 | Soft penalty |
